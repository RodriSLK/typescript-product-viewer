# 🛍️ Product Viewer - TypeScript

## 📌 Descripción del proyecto

Este repositorio contiene el desarrollo de un trabajo práctico realizado con TypeScript.

La finalidad del proyecto fue aplicar conceptos fundamentales del lenguaje mediante el consumo de una API externa, procesamiento de datos y renderizado dinámico de contenido en una página web.

La aplicación obtiene información de productos desde una API pública y muestra los resultados en una tabla HTML, incorporando además un spinner de carga mientras se realiza la petición.

---

## 🎯 Objetivos

* Practicar tipado estático con TypeScript.
* Consumir APIs utilizando `fetch`.
* Manipular dinámicamente el DOM.
* Renderizar información obtenida de servicios externos.
* Mejorar la experiencia de usuario mediante indicadores de carga.

---

## ✨ Funcionalidades implementadas

* 🌐 Consumo de API externa de productos.
* ⏳ Spinner de carga mientras se obtienen datos.
* 📋 Renderizado dinámico de tabla de productos.
* 💲 Visualización de:

  * ID
  * Nombre del producto
  * Descripción
  * Precio
